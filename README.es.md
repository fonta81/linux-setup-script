# Script de Auto-Instalación de Herramientas para Fedora

Este proyecto proporciona un script de instalación automatizada (`Fedora.sh`) para simplificar la configuración de herramientas esenciales en un sistema Fedora.

## Uso

Para ejecutar el script de instalación, ejecuta el siguiente comando en tu terminal:

```bash
sudo ./Fedora.sh
```

Esto te solicitará privilegios administrativos (si no se ejecutó ya con `sudo`) y te guiará a través de un proceso de instalación automático o interactivo.
