# Automated Fedora Tool Installation Script

This project provides an automated installation script (`Fedora.sh`) to streamline the setup of essential tools on a Fedora system.

## Usage

To run the installation script, execute the following command in your terminal:

```bash
sudo ./Fedora.sh
```

This will prompt you for administrative privileges (if not already run with `sudo`) and guide you through either an automatic or interactive installation process.
